# Frontex Exam Simulator

Practice test for the Frontex selection procedure: 1000 multiple-choice questions built from the official reference material, a 50-question / 60-minute exam simulation (+1 correct, −1 wrong, 0 unanswered, score out of 10), practice by topic or source, and a mistake review.

Open the published page and use **Add to Home Screen** (iPhone: Safari → Share; Android: Chrome → ⋮) to install it. It works offline after the first visit. Progress is stored only on the device.

Independent study tool, not affiliated with or endorsed by Frontex.
